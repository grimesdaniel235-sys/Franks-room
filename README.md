# Franks-room

A small demo site and interactive example for "Frank's Room" — a tiny web project showing a demo page and minimal JavaScript interactions.

Features

- Simple demo page (index.html)
- Minimal interactive JavaScript (app.js)
- MIT license
- GitHub Pages deploy workflow

Usage

- Open the site: GitHub Pages (after deployment) — https://grimesdaniel235-sys.github.io/Franks-room/
- Edit content: modify index.html or README.md and push to main. The Pages workflow will redeploy on push.

Development

To run locally, open index.html in a browser. No build step required.
